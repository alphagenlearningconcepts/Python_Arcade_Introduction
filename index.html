New Library & Roadmap

Meet Python Arcade & Today's Agenda

What Does Python Arcade Do?

Python Arcade is a modern Python library for building 2D games with graphics, sprites, sounds, and smooth motion. Over here, we will also be using Object-Oriented Programming (OOP) concepts to structure our game cleanly.

How Is Arcade Different from Pygame?

  • Powered by OpenGL (Fast Graphics): Unlike Pygame which draws slowly on the CPU, Arcade uses your graphics card (OpenGL) so games run super smoothly!
  • Easy Sprite Animations: Creating multi-frame sprite animations (like a running dinosaur!) was tricky in Pygame, but Arcade has built-in support to animate sprites effortlessly.

Environment Setup

Installing the Python Arcade Library

Windows Computer
1

Press Win + R, type cmd, and press Enter.

2

Run the pip install command:

pip install arcade
3

Verify installation in Python:

python -c "import arcade; print(arcade.__version__)"
Mac Computer
1

Press Cmd + Space, type Terminal, and press Return.

2

Run the pip3 install command:

pip3 install arcade
3

Verify installation in Python 3:

python3 -c "import arcade; print(arcade.__version__)"
